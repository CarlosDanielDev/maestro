# feat(tui): dock session rail on Overview with shared keyboard navigation

## Overview

Integração: a Overview (`TuiMode::Overview`, braço de render em `src/tui/ui.rs:131-142`) passa a dividir sua área de conteúdo em `[trilho 4 cols][grid]`, e a navegação passa a ser compartilhada — a seleção do trilho É a seleção do grid (`GridState`, índice flat em `src/tui/panels.rs:113-117`), movida pelas setas existentes em `handle_grid_navigation` (`src/tui/input_handler.rs:1187-1207`), com Enter abrindo o Detail pelo caminho de sempre (`src/tui/input_handler.rs:1099-1110`). Aterrisa DEPOIS de {{a2}} para não pisar no refactor das células. `k` continua sendo kill na Overview (`src/tui/input_handler.rs:1054-1062`) — por isso o trilho NÃO usa j/k (setas bastam e já existem).

## Expected Behavior

- Em `TuiMode::Overview`, `chunks[1]` é dividido horizontalmente: `Constraint::Length(4)` para o trilho, `Constraint::Min(0)` para o grid — o grid recebe a área restante e o `GridLayout::calculate` existente (`src/tui/panels.rs:31-92`) continua funcionando na largura menor.
- Setas movem a seleção compartilhada; o anel correspondente ganha destaque e a janela do trilho rola para mantê-lo visível (o scroll é o de {{s3}}).
- Enter/Espaço sobre uma session selecionada abre `TuiMode::Detail(id)` — caminho inalterado (`src/tui/input_handler.rs:1099-1110`).
- Os outros modos de TUI (Detail, dashboards, overlays) não mudam: a divisão vale só no braço Overview.
- Terminal estreito: se a largura não comporta trilho + célula mínima (40 cols, `src/tui/panels.rs:17`), o trilho esconde (sem anel) em vez de esmagar o grid — verificar: escolher o threshold exato na implementação e cobrir com snapshot.

## ADR stub

Bifurcação de navegação: (a) seleção compartilhada trilho+grid via `GridState` (setas movem os dois, destaque nos dois) — zero bindings novos, um só lugar com verdade, Enter já existe; (b) foco alternado trilho/grid com uma tecla de toggle (Tipo Tab entre painéis) — dois contextos de seleção para manter em sync, mais estado; (c) j/k no trilho — rejeitado: `k` mata a session selecionada na Overview desde sempre (`src/tui/input_handler.rs:1054-1062`), rebind é breaking. Recomendação (para discordar): (a).
