Maestro spawns and monitors multiple AI coding agents on the same project — live status, real costs, conflict-free worktrees — from one TUI dashboard.

brew install carlosdanieldev/tap/maestro --formula

honest boundaries

three things it will not pretend to be

not autonomous.

Every session stops at the gates — fmt, clippy, tests — and the PR waits for your review. Maestro coordinates the work; the OK is yours.

not a ci replacement.

No hosted runners, no yaml pipelines. It is a local TUI driving real agent CLIs on your machine, in your terminal.

not a prompt wrapper.

A real state machine, one git worktree per session, a file-claim registry against edit collisions, and cost tracking per session.
